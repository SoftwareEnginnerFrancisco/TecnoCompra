# TecnoCompra — Catálogo de productos tecnológicos

## Descripción

TecnoCompra es un prototipo académico de comercio electrónico desarrollado para practicar el diseño de interfaces web, la usabilidad y la accesibilidad.

La aplicación permite explorar un catálogo de productos tecnológicos, buscar artículos, ordenar los resultados y gestionar un carrito de compras.

## Demo en línea

Puedes probar la aplicación aquí:

**[Abrir TecnoCompra](https://softwareenginnerfrancisco.github.io/TecnoCompra/)**

## Funcionalidades

- Visualización de seis productos tecnológicos.
- Búsqueda de productos por texto.
- Ordenamiento del catálogo.
- Incorporación de productos al carrito.
- Eliminación de productos del carrito.
- Visualización del total de la compra.
- Mensajes de estado para informar las acciones realizadas.
- Interfaz adaptable a diferentes tamaños de pantalla.
- Consideraciones de accesibilidad y navegación mediante teclado.

## Tecnologías utilizadas

- **HTML5:** estructura de la interfaz.
- **CSS3:** estilos visuales y diseño adaptable.
- **JavaScript:** búsqueda, ordenamiento y gestión interactiva del carrito.

## Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta `TecnoCompra`.
3. Abre el archivo `index.html` en un navegador web.
4. Prueba la búsqueda, el ordenamiento y el carrito de compras.

No se requiere instalar dependencias para ejecutar el prototipo localmente.

## Usabilidad y accesibilidad

Durante el desarrollo se consideraron los siguientes principios:

- Consistencia visual en los componentes.
- Mensajes de estado para informar las acciones realizadas.
- Identificación clara de botones y controles.
- Navegación mediante teclado.
- Etiquetas accesibles para los elementos interactivos.
- Diseño adaptable a diferentes tamaños de pantalla.

## Alcance del proyecto

TecnoCompra es un prototipo académico con fines educativos. El carrito de compras es demostrativo y no procesa pagos reales.
